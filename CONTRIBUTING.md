# Contributing

## Reporting bugs

Open an issue describing the problem, steps to reproduce, and expected vs actual behavior.

## Submitting changes

1. Fork the repository.
2. Create a branch for your change.
3. Open a pull request against `master`.

## Code style

- 2-space indentation
- Semicolons required

## Commit messages

Follow [Conventional Commits](https://www.conventionalcommits.org/):

- `feat: ...` for new features
- `fix: ...` for bug fixes
- `docs: ...` for documentation changes
